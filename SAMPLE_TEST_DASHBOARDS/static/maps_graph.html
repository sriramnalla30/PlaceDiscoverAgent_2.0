HOW IT WORKS

From a query to a place record.

What goes in, what happens in between, and every attribute that comes out. The coverage numbers on this page were measured on real places from 40 queries across 5 Bangalore areas.

The flow, step by step

FAST MODE
1 · YOU ENTERA query such as “gyms in Koramangala Bangalore”, plus a location pin (lat, lng). Optionally a radius and a language.
2 · DASHBOARD SERVERChecks your inputs, writes the query into a one-line file q.txt, and starts the scraper program on this computer. Only one scrape runs at a time.
3 · SCRAPER BUILDS A REQUESTIt sends the same internal search request Google Maps itself uses: maps.google.com/search with tbm=map. Your pin and radius are encoded inside it. No browser window opens.
4 · GOOGLE ANSWERSIt returns a raw list of up to 20 businesses, the same Business Profile data you see in the Maps side panel: name, address, phone, rating, hours.
5 · SCRAPER PARSESIt reads the raw list and writes one JSON record per place, each with a fixed set of attributes. Nothing is guessed or written by an AI.
6 · DASHBOARD ADDS 3 FIELDSIt adds _phone_kind, _phone_e164 and _phone_shared to each place, then shows the table. These three are the dashboard's own, not Google's.

Inputs

WHAT YOU CAN CHANGE
InputRequiredWhat it doesWhat we measured
queryYESThe list search, written like you would type into Google Maps: category + area + city.A query naming one business (“Marvel Multispeciality Hospital Koramangala”) returned 0 places. Fast mode only reads list results.
lat, lngYESThe centre of the search. The scraper refuses to run in fast mode without them.This is what keeps results in the right city. Without a pin, the older Serpstack test drifted to Mumbai and Hyderabad.
radiusnoSearch radius in metres around the pin (default 10,000).1,000 m returned 11 places; 30,000 m returned 20 (the cap).
langnoLanguage for names and categories, such as hi for Hindi.Works: Hindi names came back in Devanagari.

Set by the dashboard, not by you:

-fast-modeThe only mode that worked on 30 Oct 2026. The normal mode failed on all 3 test jobs with “unexpected page type”.
-c 1One scrape at a time, to be gentle with Google.
-depth, -zoomThe scraper has these settings, but in fast mode they changed nothing: depth 1, 3 and 10 and zoom 13, 15 and 17 all returned the same 20 places.
